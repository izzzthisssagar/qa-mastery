<Hook>A red pipeline square says a test was unhappy. A useful report says which request, which assertion, which environment, and what the next investigator should inspect.</Hook>

<Callout type="analogy">Punch cards turned machine state into a durable record another system could sort. Newman reporters do the same run in several shapes: terminal for people, JUnit for CI, JSON for tools.</Callout>

<Term define="A test result report is a structured, retained account of run identity, requests, assertions, errors, timings, and outcome. Newman has built-in CLI, JSON, JUnit, progress, and emojitrain reporters; selecting a non-CLI reporter disables the default CLI output unless cli is explicitly included.">API test result report</Term>

## One run, several consumers

Use `-r cli,junit,json` when humans need immediate logs, CI needs test cases, and diagnosis needs machine-readable detail. Set explicit export paths such as `--reporter-junit-export reports/newman.xml` and `--reporter-json-export reports/newman.json`. Report artifacts should include run metadata but exclude secrets and unnecessary sensitive bodies.

<Callout type="tip">Name artifacts with suite, environment, commit, and run id. “newman.json” downloaded from five jobs is a tiny distributed-systems incident.</Callout>

<Callout type="mistake">Turning on `-r junit` alone disables the default CLI reporter. If you still want terminal output, request `-r cli,junit` explicitly.</Callout>

<CodePlayground language="python" title="Run it - summarize assertion records (Python)" code={`records = [("status is 200", True, 81), ("schema matches", False, 81), ("under 500ms", True, 81)]
passed = sum(ok for _, ok, _ in records)
failed = len(records) - passed
print(f"tests={len(records)} passed={passed} failed={failed}")
for name, ok, ms in records:
    print(f"{'PASS' if ok else 'FAIL'} | {name} | {ms}ms")`}/>

<CodePlayground language="java" title="Run it - summarize the same records (Java)" code={`import java.util.*;
public class Main {
  record Result(String name, boolean ok, int ms) {}
  public static void main(String[] args) {
    List<Result> rows = List.of(new Result("status is 200", true, 81), new Result("schema matches", false, 81), new Result("under 500ms", true, 81));
    long passed = rows.stream().filter(Result::ok).count();
    System.out.println("tests=" + rows.size() + " passed=" + passed + " failed=" + (rows.size() - passed));
    rows.forEach(r -> System.out.println((r.ok() ? "PASS" : "FAIL") + " | " + r.name() + " | " + r.ms() + "ms"));
  }
}`}/>
