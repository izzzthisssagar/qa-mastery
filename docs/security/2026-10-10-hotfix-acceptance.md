## Bounded independent review

The initial read-only Codex review identified real verification gaps (see resolved items below). A second, focused read-only Codex review then confirmed that a **draft security PR is appropriate once all corrective files are included**. The reviewer maintained a **NO-GO for merge** until live CI authenticated GraphQL tests pass and the development-only braces advisory receives an explicit risk decision. Review does not replace CI.

- **P1: Policy script skipped:** `check-runtime-alignment.mjs` used a noncanonical `file://` vs relative argv comparison, so `pnpm verify` had not actually executed its version alignment. **Fixed** with `fileURLToPath(import.meta.url) === path.resolve(process.argv[1])`; enforce Next 16.3.8 and updated js-yaml/sharp floors; 5 Node policy tests pass, including real relative CLI.
- **P1: New contract unwired:** A manually passing untracked test could be absent from the committed CI. **Fixed** with root `pnpm test:security`, explicit GitHub Actions `checks` step, and integration into `pnpm verify`. Five semantic security tests + five policy tests pass, including a CI contract guard.
- **P2: Cross-major transitive selectors:** Several overrides matched older incompatible major lines. **Fixed** by using same-major range boundaries for Next dependencies and development toolchain, with the lockfile regenerated and fresh audit unchanged.
- **P2: Text-only lockfile assertions:** **Fixed** by parsing the pnpm YAML importers, dependency snapshots and exact scoped override map rather than checking for comments or substring presence.
- **P1: Yoga compatibility coverage:** **Locally tested** unauthenticated GET/introspection, GraphiQL, OPTIONS, malformed JSON, parse error and denied mutations; **CI-only** authenticated GraphQL nested queries and write mutations are prepared in `e2e/tests/buggyapi.spec.ts`, discovered for Chromium and WebKit but not yet executed. **Merge remains blocked** until real CI passes and reviewer approves.
- **P2: Upstream braces advisory:** Clarified that the remedy is _reported_ but not available on npm; do not call the broader audit clean.

**Focused reviewer follow-up:** CI wiring and semantic lockfile checks were inspected; no new application-source defect was identified. The reviewer emphasized that `scripts/security-hotfix.test.mjs` (initially untracked) and the tracked but modified `e2e/tests/buggyapi.spec.ts` must both be included in the PR. The review sandbox could not independently execute the fixture tests because `/tmp` writes were disallowed; our own fresh local `pnpm verify` and production builds passed. The CI signed-in E2E remains deliberately **NOT RUN** until a reviewed draft PR. One high-severity development dependency remains open. No application business logic, platform auth, schema/migrations, hosted resources, grader behavior or seeded bug manifests were changed.
