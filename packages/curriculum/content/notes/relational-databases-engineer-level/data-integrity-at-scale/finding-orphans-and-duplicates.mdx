<Hook>Finding bad rows is easy; proving which row is canonical and why the damage happened is the engineering work. A cleanup without a prevention step is tomorrow’s incident queue.</Hook>

<Callout type="analogy">Duplicate records are look-alike buildings on one block: appearance is not identity. You need addresses, governed keys, and provenance. Orphans are records whose claimed address has no valid parent under the declared relationship.</Callout>

## Detect without inventing truth

Find <Term define="A row whose applicable child reference has no matching eligible parent.">orphans</Term> with `NOT EXISTS` or a left anti-join, respecting nullable relationships. Find duplicates by the normalized business key—not blindly by every column. Use `GROUP BY ... HAVING count(*) > 1` for groups and `row_number()` for deterministic review candidates.

<Callout type="tip">Materialize candidate keys and counts before repair. Review a stratified sample: largest groups, oldest groups, newest groups, and groups spanning source systems.</Callout>

<Callout type="mistake">Deleting every row with `row_number() > 1` before repointing children. A “duplicate” may own references, history, or distinct attributes that must be merged.</Callout>

<CodePlayground language="python" title="Group duplicate candidates" code={`emails = ["A@EXAMPLE.COM ", "a@example.com", "b@example.com"]
counts = {}
for email in emails:
    key = email.strip().lower()
    counts[key] = counts.get(key, 0) + 1

duplicates = {key: count for key, count in counts.items() if count > 1}
assert duplicates == {"a@example.com": 2}
print(duplicates)`}/>

<CodePlayground language="java" title="Group the same candidates in Java" code={`import java.util.*;
class Main {
  public static void main(String[] args) {
    List<String> emails = List.of("A@EXAMPLE.COM ", "a@example.com", "b@example.com");
    Map<String, Integer> counts = new TreeMap<>();
    for (String email : emails) {
      String key = email.trim().toLowerCase(Locale.ROOT);
      counts.put(key, counts.getOrDefault(key, 0) + 1);
    }
    counts.forEach((key, count) -> { if (count > 1) System.out.println(key + " -> " + count); });
  }
}`}/>
